# API для разработчиков
REST API доступен на тарифе «Нимбус Про» и в «Нимбус Бизнес». Токен создаётся в Настройки → Разработчикам. Токен показывается один раз — сохраните его.

Ограничение — 1 000 запросов в час на токен, загрузка через API — до 50 ГБ на файл. При превышении лимита API возвращает код 429.

Документация API опубликована на dev.nimbus.example.
