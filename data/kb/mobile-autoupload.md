# Автозагрузка фото и видео с телефона
Приложение «Нимбус» может автоматически загружать фото и видео из галереи телефона. Включите её в приложении: Профиль → Автозагрузка. По умолчанию загрузка идёт только по Wi-Fi; разрешить мобильный интернет можно там же.

На iPhone для автозагрузки нужно дать приложению доступ ко всем фото, а не к выбранным. Фоновая загрузка на iPhone ограничена системой, поэтому периодически открывайте приложение.

Автозагруженные файлы занимают место в хранилище по обычным правилам.
