# Публичные ссылки на файлы и папки
Чтобы поделиться файлом или папкой, откройте меню → «Поделиться» → «Создать ссылку». Любой, у кого есть ссылка, сможет скачать файл без регистрации.

На платных тарифах для ссылки можно задать пароль, срок действия и запрет скачивания (только просмотр). На «Базовом» ссылки бессрочные и без пароля.

Отозвать доступ можно, удалив ссылку в разделе «Общий доступ». Ссылки на файлы, нарушающие правила сервиса, блокируются автоматически.
