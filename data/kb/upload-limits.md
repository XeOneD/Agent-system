# Ограничения на размер файлов
На тарифе «Базовый» максимальный размер одного файла — 2 ГБ, на платных тарифах — 50 ГБ. Через браузер можно загрузить файл до 10 ГБ на любом тарифе; файлы больше загружайте через приложение для компьютера.

Количество файлов не ограничено. Загрузка прерванного большого файла продолжается с места обрыва, если не закрывать приложение дольше 24 часов.
