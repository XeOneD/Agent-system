# Хранение и защита данных
Файлы пользователей хранятся в дата-центрах на территории России и шифруются при передаче (TLS) и при хранении (AES-256). Сотрудники «Нимбуса» не просматривают содержимое файлов.

Обработка персональных данных ведётся в соответствии с 152-ФЗ. Данные передаются государственным органам только по официальному запросу в случаях, предусмотренных законом.

Сквозного шифрования (когда ключ есть только у пользователя) сейчас нет.
